Core Systems

Kernel Architecture Pipeline

An interrupt-driven higher-half monolithic kernel engineered from first principles in C and NASM Assembly. Zero external runtime libraries.

01

Boot & Initialization

Multiboot2 hand-off with memory map & framebuffer. Enters 64-bit Long Mode, sets up GDT/TSS, IDT with IST stacks, and 1000 Hz APIC timer.

GDT · IDT · APIC · PIT · PS/2
CR0.PG = 1 · EFER.LME = 1
02

Memory Management

Bitmap physical page frame allocator, 16 MB kernel heap, 4-level paging with PML4[511] higher-half mapping, and NX + SMEP page permissions.

PML4 · PDPT · PD · PT · Heap
CR3: 0x100000 (Base)
03

Processes & Scheduler

Preemptive weighted round-robin scheduling over kernel threads and ring-3 processes. Full job control: exec, spawn, jobs, wait, kill, and nice.

Context Switch · TSS · RSP0
APIC IRQ0 Vector 32
04

ELF Userspace & 57 Syscalls

ELF64 loader, embedded initramfs, fork() with COW, 57 atomic syscalls via syscall/sysret, minimal libc, and isolated per-process file descriptors.

ELF64 · Ring-3 · MSR_LSTAR
RCX = RIP · R11 = RFLAGS
05

Filesystem & VFS

Ramdisk VFS with full EXT2 read/write driver auto-mounted at /mnt, write-through sector cache, per-fd offsets, and persistence across reboots.

EXT2 Inodes · VFS Nodes · ATA
Auto-mount: /mnt
06

Network Subsystem

Realtek RTL8139 PCI NIC driver with TX/RX rings, ARP cache, IPv4 routing, ICMP echo, UDP datagrams, and full TCP with exponential RTO.

RTL8139 · TCP · UDP · poll()
DHCP · DNS · Loopback

Developer Ecosystem

In-OS C Toolchain & Compilers

NyxOS self-hosts. A ported TinyCC 0.9.27 compiles C code directly inside the operating system (tcc compiles tcc), paired with the xbm package manager and native N compiler.

[C]
Self-Hosting C

TinyCC 0.9.27 Compiler

Ported to run inside NyxOS ring-3 userspace. Emits 64-bit ELF executables directly to the EXT2 filesystem. Compiles and executes C applications in milliseconds with zero host dependencies.

tcc compiles tcc ELF64 Generator 0 Host Dependency
[PKG]
Package Manager

xbm Package Manager

The native binary package manager for NyxOS. Resolves recipe dependencies, manages disk storage in /mnt/bin, and installs user applications with checksum validation.

xbm install Recipe Engine EXT2 /mnt/bin

Documentation

Getting Started with NyxOS

Build the kernel, boot the ISO in QEMU, forward network ports, and log in to the desktop.

1

Clone & Compile

Requires x86_64-elf-gcc or host GCC with 64-bit support.

bash
git clone https://github.com/kazah-png/nyx-os.git
cd nyx-os
make -C kernel
2

Run in QEMU

Launches with GUI desktop, RTL8139 NIC, and EXT2 disk image.

QEMU Command
qemu-system-x86_64 -cdrom NyxOS.iso \
-m 256M -nic user,model=rtl8139 \
-display sdl
3

Log In to Desktop

PBKDF2-HMAC-SHA256 authenticated default credentials.

Default Credentials
Username: nyx
Password: nyx
